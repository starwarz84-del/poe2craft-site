# 반지깎는노인 — 유동체를 활용한 제작법 (IVydF9iRHes, 6:25, 0.5)
- 유동체: 저항 옵션을 화염·냉기·번개·카오스 저항으로 바꿈(같은 티어). 주얼 '특정 저항 최대치' 옵션에도 사용 가능.
- 일반 저항 → 카오스 저항(카오스 유동체)은 한 등급 높게: 1→1, 3티어 → 카오스 2티어 (영상 정리표).
- 응용1: 목걸이 절사 마무리 중 저항 1티어(레벨 82)가 들어와 세 옵션이 모두 82레벨이라 절사 불가 → 카오스 유동체로 카오스 저항 1티어(레벨 81)로 바꾸면 절사 대상이 생김.
- 응용2: 하이브리드 저항(화염+카오스 등, 티어 없음 = 1티어) → 카오스 유동체 → 카오스 저항 1티어 단일 옵션. 카오스 저항 1티어에 81레벨 베이스 불필요. 반지: 낮은 레벨 베이스로 제작 → 마지막 울라만 훼손(번개 + 카오스 저항 확정) → 카오스 유동체 → 카오스 저항 1티어.
- 응용3: 메드베드 룬 갑옷의 저항+카오스 옵션(훼손 옵션보다 수치 높음) → 카오스 유동체 → 카오스 저항 최대 41%(1티어 최대 27% 초과).
- 유동체는 같은 티어 안에서 수치를 다시 굴림 → 수치 잡기용(디바인 대신, 쌈).
- 장화 분열 준비: 매직 유효 2개 → 접두 에너지 보호막 + 접미 저항 2개 → 분열 전 디바인은 접두 에너지 보호막 수치만, 접미 저항 수치는 유동체로. 분열된 저항은 유동체로 안 바뀌어서 분열 뒤에도 나머지 저항은 다시 유동체 가능.
