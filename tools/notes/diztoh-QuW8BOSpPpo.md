## 고친 점 (그래프 `scripts/graphs/diztoh-crit-helmet-v2.json`)

예전 그래프(2026-11-09 사용자 확정 흐름)는 분열 옵션을 % 증가로, B를 최대치로 두었는데 화면은 반대예요. 자막의 "1티어 회피 및 에너지 보호막"이 실제로는 최대치 옵션이었어요. 사용자 확정 내용을 바꾸는 것이라 검수가 필요해요.

- 매직 목표·분열 성공 = 회피·에너지 보호막 최대치 1티어(`flatT1`).
- B = % 증가 또는 복합(생명력·마나) 중 먼저 뜨는 것(`pB`), C = 남은 하나. 접두 완성 = % 증가 + 복합. 예전 B 후보였던 접두 희귀도(`rarP`)는 영상이 거절(4:00)해서 뺌.
- 매직 단계에서 옵션을 다 지운 뒤 가는 곳을 변화가 아니라 확장(h3)으로.
- B 빗나감 정리 `bx`가 치명타 확률과 B를 같이 지키고, B가 지워지면 `bxy`(남은 잡옵 정리) → B부터.
- C 빗나감 하이엔드: 좌측 말소·절사 + 상위 카오스(`p3`, 정책 23④ 자동 선택 — 이 상태에서는 영상처럼 좌측 말소 1/2). B가 지워지거나 새 옵션이 접미로 가면 `p3x`(소멸의 오브, 영상 9:19·9:27) → B부터.
