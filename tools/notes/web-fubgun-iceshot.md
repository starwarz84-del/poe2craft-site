# Fubgun 0.5.5 Ice Shot Deadeye — Crafting Guide (Mobalytics, 2026-06-18 갱신)
주소: https://mobalytics.gg/poe-2/builds/ice-shot-deadeye (2026-11-11 내장 브라우저로 본문 확인)

글에 있는 제작법: 비치명타 활, 치명타 활(아이템 레벨 75), 화살통 가성비·비싼 길, 투사체 +3 목걸이, 에너지 보호막 투구 2종, 에메랄드 주얼.
레시피로 만든 것: 비치명타 활 → fubgun-phys-bow-v2, 치명타 활 → fubgun-crit-bow-v2, 화살통 가성비 → fubgun-quiver-v2, 목걸이 → fubgun-proj-amulet-v2, 투구 가성비 1번 → fubgun-es-helmet-v2.

가정(글에 없음):
- 화살통·투구 베이스 이름(본능적인 화살통, 카마사의 티아라), 활은 글의 전쟁광 활.
- 화살통 2단계 완벽한 제왕의 오브: 글은 접미면 이상적이라고 하지만 접미가 차면 다음 우측 강령술 턱뼈가 좋은 접미를 지움 → 좌측 대관식의 징조로 접두 고정. 글의 '빗나가면 상위 카오스 오브(2/3 망함)' 단계는 뺌.
- 목걸이 빗나간 저항 처리: 글은 '소멸 또는 빗장뼈 + 우측 강령술 + 빛의 징조로 지우고 다시'. 접미에 빈자리가 있으면 빗장뼈가 빈자리로 가서 안 지워짐 → 우측 소멸의 징조 + 소멸의 오브.
- 목걸이 마지막 접두: 글은 '원하는 접두' → 생명력·에너지 보호막 최대치·에너지 보호막 증가로 정함.
- 투구 마지막 바알 주입기(타락)는 정책 33으로 뺌. 에메랄드 주얼은 기존 주얼 레시피와 같은 흐름이라 안 만듦.
