# 반지깎는노인 — 8옵션 마법봉 제작법 (TmfCxzXrNK8, 4:35, 0.5)
- 세를의 승리(접미 +1)는 '장착된 룬 옵션'이라 장착 아이템 효과 증가에 영향 받음.
- 마법봉: 군왕의 합금 = 장착된 아이템 효과 증가 20~30% 옵션, 알두르 유산 룬 '룬 탐구자의 소명의 유산'(장착 효과 +75%) → 합쳐 최대 105% → 접미 +1이 +2 → 접미 5개(옵션 8개).
- 주의: 군왕의 합금 옵션(장착 효과 증가)을 절사로 지우면 +2가 +1로 돌아가고, 새 옵션이 접미로 가면 접미를 더 붙일 수 없음 → 접두를 먼저 완성하거나 레벨 높은 옵션을 접두에 두고 접미 절사. 군왕 옵션이 없어지면 절사 불가.
- 접두 유효: 주문 피해·원소 피해·마나 최대치 + 주문 스킬 +1.
- 결론: 6소켓 세스랑(셉터?)이 비용·난이도 대비 합리적, 마법봉은 축성·타락으로 극한까지 갈 때만.
