# 반지깎는노인 — 미러 지팡이 제작 방법 (vT482uJFESs, 9:46, 약 10개월 전 = 0.4 무렵) — 레시피 후보 · 자막 전체 다시 확인 2026-11-11(메인 세션)
대상 옵션: 접두 주문 피해 % 1티어(분열) · 번개(또는 냉기) 피해 % 1티어 · 피해의 x%를 추가 번개(냉기) 피해로 획득 / 접미 모든 번개(냉기) 주문 스킬 +7 · 시전 속도 1티어 · 주문 치명타 확률 1티어.
- 지팡이는 베이스마다 나오는 옵션이 정해짐(예: 전도성 지팡이 = 번개 피해 %·번개 주문 레벨만, 화염·냉기 등은 안 나옴) → 옵션에 맞는 베이스를 고르면 확률이 큼. poe2db 가중치는 베이스 제한을 반영 안 함(영상의 계산: 차인벨 0.091% / 전도성 0.11~0.45% → 카오스 약 1,100 / 900~220개).
- 영상 당시 가중치(poe2db): 주문 피해 % 1티어 50, 번개 피해 % 1티어 50, 추가 번개 1티어 500, 번개 주문 +7 100, 시전 속도 250, 주문 치명타 125.
- 순서: 주문 피해 % 1티어 분열 → **빈자리를 모두 연 채로**(이미 뽑힌 옵션은 안 나옴) 카오스 오브로 번개 주문 +7 → 절사로 시전 속도 → 절사로 주문 치명타 1티어(번개 주문 +7 레벨 81, 시전 속도 80이라 절사에 안 지워짐). 절사 중 새 옵션이 접두로 가서 추가 번개 1티어(레벨 80)가 붙으면 두면 접미만 돌아가게 됨.
- 접두: 추가 번개 1티어 2개(또는 번개)면 좌측 결정화 + 심연의 에센스(1/2로 살림) → 징표 훼손으로 번개 피해 % 1티어 노림 → 아니면 빛의 징조로 지우고 다시 심연의 에센스. 공개에 번개 피해 %가 없으면 마나 최대치(가중치 1,000으로 가장 흔함)를 먼저 받아 두고 남은 접두를 완벽한 엑잘로(마나가 빠진 풀 = 주문 피해·마나 복합·번개 피해 %·추가 화염/냉기/번개 5개) → 실패하면 빛의 징조로 훼손 옵션을 지우고 반복, 번개 피해 %가 훼손으로 나오면 남은 자리는 절사로 추가 번개.
- 원칙: 계획을 세워 '처음부터 다시'(태초 마을) 없이 확실하게.

- 마지막 접두(9:20 '나머지 한 자리는 절사'): 주문 치명타 1티어가 레벨 76으로 가장 낮아 절사만 쓰면 그 옵션이 지워짐 → 플로우차트는 좌측 말소를 같이 씀(pT). 영상은 말소를 말하지 않음.
