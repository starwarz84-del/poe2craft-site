# BigDaddyGaming 0.5 Wand Crafting Guide (Mobalytics, 2026-06-02)
주소: https://mobalytics.gg/poe-2/profile/bigdaddygaming/guides/0-5-7-wand-crafting-guide
결투 마법봉 아이템 레벨 81, 모든 번개 주문 +5 분열(접미). 레시피: bigdaddy-lightning-wand-v2(가성비 길).
- 분열 준비: +5 + 옵션 2개 + 턱뼈 미공개 훼손 → 분열의 오브 1/3 (시작 상태로 뺌, 정책 2).
- 카오스 오브로 주문 치명타를 분열 외 유일한 옵션으로 → 좌측 찬미 + 엑잘 → 좌측 결정화 + 초월의 합금.
- 가성비 길: 보존된 턱뼈 + 심연의 메아리로 마나 최대치(복합 아님)를 공개해 접두 자리 막기 → 상위 찬미 + 상위/완벽한 엑잘 → 빛의 징조로 막기 제거 → 보존된 턱뼈 → 마지막 공개.
- 비싼 길(+7): 아스트리드의 창의성 → 엑잘(마나면 좌측 말소 + 카오스) → 좌측 결정화 + 천공의 합금 → 턱뼈로 복합 마나·주문 피해 막기 → 완벽한 엑잘 → 빛의 징조 → 턱뼈(고대) 공개 → 룬 교체. 레시피로는 안 만듦(꿀팁 수준).
가정: 마나 막기 공개가 빗나가면 빛의 징조로 다시(밸런스), 에센셜은 공개된 옵션을 그대로 막기로 씀.
