4:22 콜르의 사냥을 끼우고(영구), 완벽한 진화·확장·제왕(4:36~5:06) 뒤 소멸의 오브로 옵션을 하나만 남겨요(5:32). 그 상태로 카오스 오브를 돌려 모든 투사체 스킬 레벨 +2를 얻어요(6:32). 중간에 치명타 1티어가 뜨자 우측 찬미 + 상위 엑잘로 +2를 노려 보지만 치명타가 지워지고 다시 카오스로 돌아가요(6:02~6:16).

분열의 오브는 옵션이 4개 있어야 써요. 완벽한 엑잘 + 좌측 찬미 + 상위 찬미의 징조로 접두 2개를 붙이고(6:58 징조 소모 메시지, 7:45 자막), 고대 갈비뼈 + 우측 강령술의 징조로 접미에 훼손 옵션을 붙여요(7:04·7:13·7:32). 훼손 옵션은 분열되지 않아 1/3이에요. 영상은 장갑 셋이 빗나가고 네 번째(8:57)에 성공해요. 빗나간 장갑은 버리고 새 30% 장갑으로 처음부터 해요. 네 번째 장갑에는 분열 전에 아스트리드의 창의성 + 좌측 결정화 + 발작의 에센스·군왕의 합금으로 잡옵 접두를 바꿔 두는데(8:15~8:47), 분열이 빗나가도 쓸 수 있게 하려는 보험이에요.

## 플로우차트

베이스템 완성: 특출난 검은강철 건틀릿(12디바인) → 퀄리티 30%(옆 상자, 비용 미포함) → 콜르의 사냥(옆 상자) → 완벽한 진화 → 완벽한 확장 → 완벽한 제왕 → 소멸로 옵션 1개 → 카오스 오브(+2만) → 완벽한 엑잘 + 좌측 찬미 + 상위 찬미 → 고대 갈비뼈 + 우측 강령술 → 분열(빗나가면 새 베이스) → 분열 + 옵션 1개.
옵션 추가 작업: 아스트리드의 창의성 → 카오스 오브(투사체 속도·피해 / 치명타 확률·관통 1티어) → 4A는 xs·csA·csH·asx, 4B는 xp·cpA·apx → 빈 제작 옵션은 js·jh(발작)·jp·ja(합금) → 고대 갈비뼈(k15) → 공개(k16) → 빛의 징조 + 소멸(k16x).

등급은 하이엔드·밸런스 두 개예요(전문가). 하이엔드는 영상 그대로 모든 반복과 공개가 1티어예요. 밸런스는 정책 10장 C17대로 상위 엑잘 반복과 빛의 징조 공개를 1~2티어로 받아요. 분열 뒤 카오스 오브는 싼 반복이라 두 등급 모두 1티어예요(C15).

## 이번에 고친 곳

- 투사체 +2 태그에 1티어 제한이 없어 카오스 오브가 +1(2티어)에서도 멈췄어요. 영상은 +2만 써요 → `proj` tmax 1.
- 관통 태그에 티어 제한이 없었어요. 15:40에 관통 25%(2티어)를 버리니 1티어만 성공 → 하이엔드 1티어, 밸런스 1~2티어.
- 베이스 준비에 영상 단계를 넣었어요: 제왕 뒤 소멸로 옵션 1개(5:32), 완벽한 엑잘 + 좌측 찬미 + 상위 찬미로 접두 2개(6:58), 훼손은 보존된 갈비뼈 → 고대 갈비뼈 + 우측 강령술의 징조(7:04·7:13).
- 베이스 값 12디바인(노트)을 넣었어요. 예전엔 0이었어요.
- 밸런스는 예전에 공개 결과를 그대로 두었는데, C17 3번(밸런스도 빛의 징조)에 맞춰 1~2티어까지 빛의 징조로 다시 하게 바꿨어요.
- 그림: 소멸 상자(12.C·13.B)에서 '처음으로' 선이 숨어 있어 들어오는 선이 없던 kz 상자에 선을 그렸어요. 빛의 징조 상자 → 고대 갈비뼈로 돌아가는 선도 숨어 있어 그렸어요. 상위 엑잘 상자의 확률은 성공 뒤 갈 수 있는 숨은 길(k15·완성 등)도 성공으로 세게 했어요(예전엔 일부만 세어 0.6%처럼 낮게 나옴). xp → 소멸 선은 '접두가 꽉 찬 성공' 조건에 빨간 색이 칠해지던 것을 실제 빗나감 조건으로 옮겼어요.

## 영상과 다르게 둔 곳 (내부 결정)

- 퀄리티 30%는 옆 상자로만 두고 비용에 넣지 않았어요. 영상 숫자는 장갑 24개 × 12디바인 + 주입기 65개 × 2.7디바인이고, 30% 장갑 하나에 300~400디바인이라는 말도 있어요. 분열이 빗나가면 새 30% 장갑이 필요하니 30%로 하면 실제 비용은 베이스 수(약 3개)만큼 크게 늘어요.
- 5:15의 '분열 전에 좋은 옵션 2~3개'는 권장일 뿐 장갑 1~3에서 지키지 않아 넣지 않았어요. 단계별 기대값 계산(엔진)의 준비 비용 1,222디바인은 대부분 이 권장 단계를 넣은 예전 레시피의 좌측 소멸의 징조(약 1,118디바인)예요.
- 6:02~6:16의 치명타 1티어 보호 시도, 8:15~8:47의 분열 전 보험(아스트리드 + 결정화 + 발작·합금 + 신성한 오브), 14:30 심연의 에센스 실험, 17:20 룬벼림, 신성한 오브, 룬 교체는 뺐어요.
- 아스트리드의 창의성은 영상에서 분열 전(8:15)에 끼우지만 분열 뒤 첫 단계로 둬요(정책 5장: 제작 옵션이 2개 되기 전이면 어디든 같음).
- 4A에서 첫 엑잘에 맞으면 룬 수호가 없어요. 노트 4B와 13:05 '옵션 5개를 채우고 마지막을 훼손'에 맞춰 jp·ja(접두 잡옵 + 좌측 결정화 + 군왕의 합금)로 채워요. js·jp에 쓰는 엑잘티드 오브 종류는 영상에 없어 일반 엑잘티드 오브로 뒀어요.
- 3단계 노트의 접미 후보에 치명타 피해가 있지만 콜르 옵션이 아니고 데모에서 노린 적이 없어 카오스 단계 후보에서 뺐어요.
