## 낮은 점수 분석

**2026-11-11 · MazBro 투사체 장갑(하이엔드·밸런스) 60점 → 95점**

- 원인: 콜르의 사냥 옵션(증강물 x 옵션)은 SL 실험 가중치(`wsrc:'sl'`)를 시뮬만 쓰고, 레시피 엔진은 그 단계를 '가중치 모름'으로 확률 1 처리 → 비용이 0에 가까워 등급 차이도 사라짐. 레시피에 남아 있던 옛 `unknownW` 표시도 같은 이유.
- 해결: 엔진(recipes.html `addChance`)이 장착된 증강물 룬의 SL 측정 옵션을 엑잘·카오스 풀에 넣고, 목표가 모두 SL 측정 옵션이면 `unknownW`·`specUnknown`을 무시. 같이 오른 것: SL 7옵션 장갑 70 → 100점(엔진 983 vs 시뮬 1,104 div), 시한 투사체 장갑 80 → 90·95점, Diztoh 소켓 장갑 90 → 90·95점.
- 덤으로 찾은 것: `_score.js`가 화면이 처음 그릴 때 만든 분석 캐시(`r._an`, 클래스 파일을 받기 전)를 그대로 읽어 '가중치 모름'이 남아 보이던 문제 → 매번 캐시를 지우고 다시 계산.
