# 글쓰기 기준 (사용자 제공 2026-11-11)

사용자에게 보내는 답, 화면 문구, 꿀팁, 문서에 적용해요. 한 글에 여러 개가 몰려 있을 때 고쳐요.

## 1. 문장 패턴
- 'A가 아니라 B' 대구를 연달아 쓰지 않는다. 정말 둘을 구분할 때 한 번만 쓴다.
- 무엇이든 세 개로 맞춰 나열하지 않는다. 내용이 두 개면 두 개, 다섯 개면 다섯 개.
- 같은 대상을 문단마다 다른 말로 바꿔 부르지 않는다. 처음 정한 이름을 끝까지 쓴다.
- 문장 끝에 의미를 덧붙이는 꼬리를 쓰지 않는다: "~라는 점에서 의미가 크다", "~을 보여 준다", "~을 시사한다".
- 상투적인 맺음을 쓰지 않는다: "결론적으로", "종합하면", "시사하는 바가 크다". 문단마다 정리 문장을 붙이지 않는다.
- 가르치는 말투를 피한다: "주목할 점은", "기억해야 할 것은", "~을 짚어 볼 필요가 있다".
- 출처 없는 권위를 쓰지 않는다: "전문가들은", "업계에서는" 뒤에는 이름이나 출처를 댄다.
- 근거 없는 칭찬·과장을 쓰지 않는다: "혁신적인", "획기적인", "새로운 기반" 대신 날짜·숫자·사실을 쓴다.

## 2. 한국어 번역투
- 이중 피동 금지: "보여집니다" → "보입니다", "생각되어집니다" → "생각합니다".
- 영어식 대명사 직역 금지: "그것은", "그의 손을" → 빼거나 이름으로.
- 군더더기 연결어 줄이기: "~에 있어서" → "~에서", "~를 통해" → 동사로 풀기.
- 쉬운 동사 쓰기: "기준으로 기능합니다" → "기준입니다", "구매하다" → "사다".
- 한국어로 충분한 말을 영어로 쓰지 않는다.
- '것·점·바' 같은 형식 명사를 줄인다.

## 3. 리듬과 구조
- 모든 문장을 같은 길이로 쓰지 않는다. 짧은 문장과 긴 문장을 섞는다.
- 한 문단 안에서 같은 문장 구조를 세 번 이상 되풀이하지 않는다.
- 같은 어미를 연속으로 쓰지 않는다.
- 숫자로 글을 시작하기보다 장면, 의외의 사실, 판정으로 연다. 숫자는 바로 뒤에.
- 결론을 마지막에 다시 요약하지 않는다. 열린 질문이나 짧은 한 줄로 끝낸다.
- 설명은 독자가 모를 때만, 꼭 필요한 만큼. 앞 단어를 풀어 주는 괄호는 최대한 줄이고 주석으로 보낸다.

## 4. 서식
- 굵은 글씨, 글머리표, 이모지를 남발하지 않는다.
- "핵심 요약"처럼 굵은 소제목 + 쌍점 목록을 습관처럼 쓰지 않는다.
- 요약·목록 개수를 미리 정해 두고 끼워 맞추지 않는다.

## 5. 그림·도표 속 글자
- 그림 안 문구는 명사형 라벨로 쓴다. "~다", "~었다" 같은 문장 어미를 쓰지 않는다.
- 그림 제목이 곧 결론이다. 해석 문장은 본문에서 한다.

## 6. 점검 방법
- 다 쓴 뒤 소리 내어 읽는다. 이중 피동과 대구가 특히 잘 걸린다.
- 위 패턴 하나는 사람도 쓴다. 한 글에 여러 개가 몰려 있을 때 고친다.
- 고친 문장이 원래 자료와 맞는지 다시 확인한다. 다듬다가 없던 사실이 들어가기 쉽다.
