- **속성부여 옵션 고르기**(사용자 확정 2026-11-11 14:53): 아이템 칸에서 자리를 고르지 않음. 옵션 목록 줄마다 왼쪽 '선택/취소' 버튼 + 옵션 + 티어 드롭다운(기본 = '모두' = 그 아이템 레벨에서 나오는 모든 티어 `lowTier`, 'T3 이상' = 그 티어 이상, 오른쪽 확률도 고른 범위, `S.pick`·`tierLbl`, 사용자 확정 2026-11-11 15:20) → 선택하면 그쪽의 빈자리에 위에서부터(`targetFor`, 특수 옵션은 쪽이 꽉 차면 추가 제작 옵션 자리), 아이템 칸 ×나 목록의 '취소'로 빼면 아래 옵션이 한 칸씩 올라감(`removeAt`·`compact`, 룬도 위에서부터). 슬롯의 티어 = 최소 티어(옛 공유 코드의 '허용 티어'는 최소 티어로 읽음). 화면 문구는 명사형으로 정리. 옵션 목록 위 = 필터 탭 '접두 옵션(모두·일반·훼손·에센스·기타) | 접미 옵션(…) | 룬 | 타락'(`#ftabs`·`S.side`·`FSUB`, 옛 옵션 분류 드롭다운 2개·안내 문구는 뺌, 2026-11-11 15:26). 아이템 칸 옵션 = 2줄(옵션 문구 / 티어·티어명·아이템 레벨 + 오른쪽 '필수 옵션/유효 옵션'·'분열' 버튼).
- **옵션 개수가 줄어드는 베이스의 매직 자리**(사용자 확정 2026-11-11): 매직 자리 = 접두·접미마다 min(1, 1 + 그쪽 증감)(`magicCap`, 에뮬레이터·속성부여). 부재 목걸이(−1/−1) = 매직 불가 → 진화의 오브 막힘, 노멀에서 제왕의 오브로 바로 희귀. 한탄(접두 −1)·석양·뒤틀린 = 매직은 접미만, 전조·황혼·왜곡된 = 접두만. **스킬 부여 베이스는 스킬 하나를 고르는 드롭다운**('부여 스킬', `skillIdx`·`impOf`/`implicits`, 에뮬레이터 `it.skill`, 속성부여 `S.skill`·공유 코드 `sk`).
