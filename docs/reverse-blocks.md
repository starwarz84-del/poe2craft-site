# 리버스 크래프팅 블록 카탈로그

사용자 확정 2026-11-11 23:22: 리버스 초안을 규칙 나열(`makeDraft`) 대신 **루프 블록**으로 만든다. 블록 = 아이템을 한 상태에서 다음 상태로 옮기는 반복 구간 하나. 블록마다 해결 방법 후보를 두고, 지금 상태와 시세로 기대 비용을 계산해 가장 싼 방법을 고른다.

근거는 등록 플로우차트 77개의 반복 구간(가장 많은 것: 징조 없는 카오스 반복 80곳, 엑잘 반복 15·면 찬미 엑잘 12, 절사 카오스 11, 소멸 10, 빛 + 소멸 9)과 `docs/crafting-stages.md`의 구간별 방법이에요.

## 구조

```
목표(필수·유효 옵션) → 계획기: 다음에 풀 블록을 고름(제작 순서) → 블록: 방법 후보마다 기대 비용 → 가장 싼 방법
                                                                  → 그래프 조각(노드·간선)을 바로 만듦 → 시뮬로 확인
```

- 블록은 한 줄짜리 초안을 거치지 않고 **그래프 조각을 바로 만든다**. 초안 → 그래프 변환에서 뜻이 빠지던 문제(유효 옵션 재시도, 증강물 풀 누락)를 없앰.
- 블록은 서로 독립: 새 노하우 = 블록 하나에 방법 하나 추가. 다른 블록 코드를 건드리지 않음.
- 비용 비교는 두 단계: ① 빠른 계산(가중치 확률 × 시세, 1ms 단위)으로 모든 방법을 거름 ② 상위 2~3개만 시뮬로 확인(정책 0장: 비용 기준은 시뮬).
- '정리'(빗나간 옵션 지우기)는 그 자체가 블록이고, 다른 블록이 빗나갔을 때 불러 씀. 비용 과다의 뿌리가 여기라서 정리 방법은 항상 시세로 고름.

## 상태 (블록이 읽는 것)

면마다 옵션 수·남은 자리, 분열 옵션, 이미 만든 좋은 옵션(지키는 옵션), 잡옵 수, 제작 옵션 수와 한도(아스트리드), 훼손 옵션·미공개·징표 유무, 퀄리티·기폭제, 룬, 아이템 레벨, 면별 최고 요구 레벨(절사 안전 판단용).

## 블록 목록

비용 식의 기호: c = 시세(div), p = 한 번에 맞을 확률(가중치), r = 지키는 옵션을 잃을 확률, R = 잃었을 때 다시 쌓는 비용.

### B1 베이스 준비 (루프 아님)
- 하는 일: 베이스 종류·아이템 레벨·특출난 베이스·먼저 끼울 룬(증강물 옵션을 여는 룬, 세를의 승리 시점)·퀄리티
- 방법: 노멀 베이스 / 매직 베이스 구입 / 분열 매물 구입('베이스에 포함') — 매물 시세가 있으면 직접 만드는 B2·B3 비용과 비교

### B2 매직 단계 굴리기
- 목표: 매직 아이템에 원하는 옵션 1~2개
- 방법: 진화·확장 반복(일반/상위/완벽 — 최소 레벨로 1티어 확정이 되는지) · 일반·상위 에센스로 레어 전환하며 확정 옵션
- 비용: (c_오브) / p, 빗나가면 소멸 또는 새 베이스(싼 쪽)

### B3 분열
- 목표: 원하는 옵션 하나를 분열로 고정
- 준비: 옵션 4개 이상(미공개 훼손 1개 포함 가능, 분열 안 걸림) → 원하는 옵션 k개면 성공 k/(공개된 옵션 수)
- 방법: 좋은 옵션 3개 + 미공개 훼손 / 좋은 옵션 2개 + 잡옵 / 확정 옵션(에센스)을 안전줄로
- 실패: 새 베이스부터(B2) 또는 실패 매물 판매로 일부 회수
- 비용: (B2 비용 + c_분열) / 성공률

### B4 고립 카오스 (K1, 80곳)
- 목표: 분열 + 잡옵 1개 상태에서 그 한 자리를 원하는 옵션으로
- 방법: 징조 없는 카오스 반복(바꿀 수 있는 옵션이 하나뿐이라 안전)
- 비용: c_카오스 / p. 가중치가 아주 낮으면 자리를 채운 채 카오스(이미 있는 계열이 빠져 p가 커짐)와 비교

### B5 빈자리 엑잘 (가장 흔한 비용 구간)
- 목표: 한 면에 원하는 옵션 하나(또는 둘)
- 시도 방법: 엑잘 / 면 찬미 + 엑잘 / 상위 찬미(둘 한 번에) / 상위·완벽 엑잘(최소 레벨) / 촉진 찬미(장신구, B11)
- 빗나감 → 정리 블록 B6 호출
- 비용: (c_시도 + (1−p) × B6 비용) / p

### B6 정리 — 빗나간 옵션 지우기
가장 싼 것부터. 상태 조건이 맞는 것만 후보.

| 방법 | 조건 | 비용 |
|---|---|---|
| 징조 없는 소멸 | 지울 수 있는 옵션이 그 잡옵 하나뿐(나머지는 분열) | c_소멸 |
| 징조 없는 소멸(도박) | 지키는 옵션이 남아 있음 | c_소멸 + r × R |
| 카오스로 바꾸기 | 다음 목표가 같은 자리 | c_카오스, 성공이면 B5 한 번 아낌 |
| 결정화 + 심연의 에센스 → 징표 → 보존된 뼈 → 공개 또는 빛 + 소멸 (K3) | 제작 옵션 자리 비어 있음, 훼손 없음 | 약 1 div |
| 결정화 + 합금·완벽한 에센스 | 그 면에 확정 옵션도 필요 | 합금 값(정리와 제작이 한 번에) |
| 면 소멸의 징조 + 소멸 | 그 밖 | 10~20 div + c_소멸 |
| 남겨 두고 순서 바꾸기 | 반대쪽을 먼저 끝내면 나중에 징조 없이 지울 수 있음 | 0 (블록 순서 변경) |

### B7 같은 면 남은 자리 바꾸기
- 목표: 면이 꽉 찬 상태에서 잡옵 하나를 원하는 옵션으로
- 방법: 절사의 징조 + 카오스(지키는 옵션이 모두 더 높은 레벨일 때만 안전) / 면 말소 + 카오스(새 옵션은 아무 면 — 반대쪽 빈자리 주의) / 절사 + 말소 같이 / 면 소멸 + 엑잘
- 준비 하위 블록: 절사 안전 만들기(높은 레벨부터 찾기, 반대쪽을 레벨 높은 옵션으로 막기, 말소로 낮은 잡옵 만들기)
- 비용: (c_카오스 + c_징조) / p + r × R

### B8 확정 옵션 (에센스·합금)
- 목표: 확정 옵션 하나
- 방법: 결정화 + 완벽한 에센스·합금(그 면 잡옵만 지워지게 — 성공 = 잡옵 수 ÷ 지울 수 있는 수) / 일반·상위 에센스로 매직 → 레어(B2와 합침)
- 조건: 제작 옵션 한도(아스트리드 필요 여부), 균열의 에센스 최대 퀄리티가 있으면 먼저 지움

### B9 훼손 공개 (76곳)
- 목표: 원하는 옵션을 훼손 공개로
- 방법: 면 강령술 + 뼈(보존된/고대: 목표 티어 레벨이 40 미만이면 보존된) + 메아리 / 군주 징조(무기·장신구, 그 군주 옵션) / 징표가 있으면 징표 자리
- 빗나감: 빛 + 소멸 / 빛 없이 면 소멸 1/2 도박 / 남겨 두고 엑잘 먼저(나중 정리에서 같이 지움) / 결정화 + 완벽한 에센스로 훼손 지우고 징표(아스트리드 필요)
- 비용: (c_뼈 + c_징조 + c_메아리 + (1−p₂) × 빗나감 비용) / p₂, p₂ = 1 − (1 − p₃)²

### B10 자리 막기 (K7·K26, B5를 감쌈)
- 목표: 가중치 높은 잡옵이 엑잘 자리를 뺏을 때 그 계열을 먼저 훼손으로 막고 B5, 끝나면 빛의 징조로 지우고 B9
- 비용: B9(막기) + B5(막힌 상태 p로) + c_빛 vs 그냥 B5 — 싼 쪽

### B11 촉진 엑잘 (장신구)
- 목표: 특정 속성 옵션
- 방법: 균열의 에센스 → 기폭제 → 촉진하는 찬미 + 면 찬미 + 엑잘, 엑잘마다 기폭제 다시
- 확률: 기폭제 퀄리티 %(추정)

### B12 주얼 다섯 번째 옵션
- 목표: 한쪽 면 옵션 3개
- 방법: 반대쪽을 잡옵 2개로 채움 → 위력적인 액체 경멸(접두가 지워지면 접두용) → 세 번째 옵션 → '+1 허용' 정리(면 소멸 / 면 말소 + 카오스)

### B13 마무리 (루프 아님)
- 퀄리티(스킬 +1 기준 34%·40%), 마지막 기폭제, 룬 교체, 축성 순서, 타락(선택)

## 계획기 (블록 고르는 순서)

1. B1 → (분열 있으면) B2·B3 또는 분열 매물
2. 분열 직후 B4
3. 분열 반대쪽 면 먼저(B5, 정리가 싸짐), 그다음 분열 면
4. 같은 면 마지막 자리는 B7, 확정 옵션은 B8(어려움 이하는 먼저, 전문가 이상은 좋은 옵션 뒤 — 정책 17)
5. 훼손 자리는 마지막(B9), 가중치 높은 잡옵 문제면 B10
6. B13

순서 자체도 후보로 둠(면 순서 바꾸기, B8 먼저/나중). 전체 비용 = 블록 비용의 합 + 잃을 위험.

## 관리 방법

- 블록마다 이 문서에 한 칸: 방법 후보, 조건, 비용 식, 근거(K 번호·레시피), 구현 상태
- 새 노하우 = 그 블록에 방법 한 줄 추가 + `docs/crafting-knowhow.md`의 K 번호
- 시험: 블록마다 '정답 상태' 시험 몇 개(예: 분열 + 잡옵 1 + 반대쪽 빈 면 → B6은 징조 없는 소멸이어야 함). 블록 단위로 시뮬 값과 빠른 계산 값이 맞는지 확인
