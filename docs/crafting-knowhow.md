# 제작 노하우 모음 (상황 → 방법)

사용자 요청(2026-11-11): 기존 제작 방법 외에 심연의 에센스·균열의 에센스·아스트리드의 창의성으로 비싼 징조 줄이기, 완벽한 에센스로 비용 줄이기 등 특수 상황 노하우를 모으고 상황에 맞춰 적용.
출처는 이 문서에만 적고 화면에는 넣지 않아요(정책: 화면은 간결하게). 우리 영상 레시피에서 나온 요령은 제작 꿀팁(`site/data/tips.json`) 번호로 연결.
시세 비교는 `site/data/prices.json`(2026-11-09 스냅숏, 1 디바인 = 363 엑잘) 기준.

**리버스 적용** 칸: 자동 = 초안 만들 때 항상 적용 · 선택 = 노하우를 적용한 초안과 기본 초안 중 더 싼 것을 고름(`bestDraft`) · 제안 = 아직 초안에 넣지 않음(다음 연습 후보).

## 가장 먼저 볼 숫자: 무엇이 비싼가

| 쓸 것 | 시세(div) | 비고 |
|---|---|---|
| 좌측 소멸의 징조 / 우측 소멸의 징조 | 약 20 / 10 | 엑잘 실패 정리에 반복으로 쓰면 비용 대부분 |
| 좌측 말소의 징조 / 우측 말소의 징조 | 약 20 / 13 | 말소 카오스 반복 |
| 절사의 징조 | 약 11 | 절사 카오스 반복 |
| 빛의 징조 | 약 7 | 훼손 공개 다시 하기 |
| 고대 갈비뼈 등 고대 뼈 | 약 2 | 레벨 40 이상만 공개 |
| 소멸의 오브 | 약 0.4 | 징조 없이 쓰면 쌈 |
| 결정화의 징조 + 심연의 에센스 | 약 0.06 + 0.01 | 한쪽 면 옵션 하나를 지우고 징표 |
| 엑잘·찬미 징조·상위 찬미 징조·보존된 뼈·심연의 메아리 | 0.003~0.06 | 거의 공짜 |

→ 비싼 것은 **면을 정하는 소멸·말소 징조와 절사·빛의 징조**뿐이에요. 노하우 대부분은 이것들을 덜 쓰는 방법이에요.
