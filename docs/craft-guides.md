# POE2 0.5 제작 글 정리(리버스 시험용)

2026-11-14 GUIDE1 조사. 리버스 크래프팅(발굴 탭)의 아이템 선정, 필수·유효 옵션 고르기, 방법 찾기를 시험하려고 모은 외부 제작 글이에요. 레시피 탭에 올리지 않는 테스트 데이터예요(사용자 결정 11-14 17:06). 원문 문장은 옮기지 않고 우리 말로 줄였어요.

같은 내용의 구조 데이터는 `docs/craft-guides.json`, 리버스에 붙여 넣을 완성품 글은 `tools/test/guides/<id>.txt`예요. 옵션 번호(gi)는 `site/data/c/<클래스>.json`의 `groups` 순서이고, 옵션 이름은 그 파일의 1티어 한국어 글이에요.

## 읽기 전에

0.5(돌아온 고대인, 룬 리그 5/29 시작)와 0.5.5(금단의 의식) 기준 글을 찾았지만, 0.5.x라고 밝힌 글 중 단계까지 구체적인 텍스트 글은 드물었어요. 유튜브 영상 위주로 공유되고, 텍스트 글은 일반론이 많아요. 한국어 글(인벤·디시·네이버)은 검색에 0.5 제작 글이 걸리지 않았어요. poebuilds.cc 목록은 robots 차단, mmogah·poecurrency·u4gm 0.5.5 글은 받기 실패, Forge of Exiles는 이미 private 테스트 데이터라 쓰지 않았어요.

그래서 `grade`로 구체성을 나눴어요. 상 = 단계·옵션·실패 처리가 다 있음, 중 = 단계는 있고 티어가 느슨함, 하 = 슬롯 목표와 일반 흐름만 있어 옵션을 우리가 맞춤. g18~g20은 0.5 이전 글(비교용, 0.5에서 사라진 동질화하는 찬미의 징조·재조합기를 씀)이라 0.5 시험 세트에서 빼도 돼요. 0.5에서 확인된 바뀐 점: 아이템당 제작(에센스) 옵션 1개, 재조합기 꺼짐, 신성한 오브가 현재 값 기준으로 곱함.

### g01-kolr-proj-gloves — +2 투사체 스킬 장갑(콜르의 사냥)

출처 https://gamesfuze.com/guides/path-of-exile-2-0-5-how-to-craft-2-projectile-skill-gloves/ · 2026-06-14 · 패치 0.5 · en · Argie Maputi(GamesFuze) · 등급 중

아이템: 장갑, 전쟁 싸개(War Wraps, 클래스 `Gloves_dex_int` 베이스 9), 아이템 레벨 82

필수: 모든 투사체 스킬 레벨 +2 (gi 85) 1티어 이상 증강물
유효(아무거나): 투사체 피해 (31—40)% 증가 (gi 74) / +(51—66)%의 초과 확률로 추가 투사체 발사 (gi 79) / (51—100)%의 확률로 적 관통 (gi 78) — 1티어 이상
버려도 됨(완성품 글의 잡옵): 생명력 최대치 +(120—149), 마나 최대치 +(105—124), 민첩 +(34—36), 화염 저항 +(41—45)%

방법
1. 아이템 레벨 82 이상 노멀 장갑(특출난 전쟁 싸개, 홈 2개)에 콜르의 사냥을 박아 명사수 옵션이 붙을 수 있게 함
2. 완벽한 진화의 오브 → 완벽한 확장의 오브로 매직 2옵션, 마음에 안 들면 소멸의 오브 후 다시 진화
3. 상위·완벽한 제왕의 오브로 희귀 전환, +2 투사체 스킬이 없으면 카오스 오브 반복
4. 엑잘티드 오브로 6옵션까지 채움
5. 심연의 메아리의 징조를 켜고 영혼의 우물에서 훼손 옵션 공개(1회 다시 굴림)
6. 방어구 장인의 고철로 퀄리티 20, 원하면 신성한 오브, 마지막에 바알 오브(3번째 홈 노림)

비용: 베이스 몇 디바인, 콜르의 사냥 수백 엑잘~2 디바인, 카오스 반복 비용은 글에 수치 없음

리버스 메모: 증강물(콜르의 사냥) x 옵션이 필수라 리버스가 지금 가중치를 모름(시뮬만 SL 추정) — 증강물 가중치 필요, 명사수 옵션은 유효 옵션군으로

버려도 됨(완성품 글의 잡옵): 민첩 +(31—33), 처치한 적 하나당 생명력 (69—84) 획득, 처치한 적 하나당 마나 (36—45) 획득

3. 좌측 강령술의 징조 + 보존된 턱뼈로 훼손 접두, 영혼의 우물에서 물리 관련 옵션 고름

5. 대장장이의 숫돌 퀄리티 20, 숙련공의 오브 홈 2개 + 상위 철 룬

비용: 빛의 징조로 훼손 다시 하기는 몇 디바인, 나머지 수치 없음

리버스 메모: 가능 — 필수 2개(물리 % · 에센스 물리 추가) + 훼손 접두 유효 옵션군, 지금 리버스로 바로 시험 가능

유효(아무거나): 공격 속도 (2—4)% 증가 (gi 7) / 이동 속도 (1—2)% 증가 (gi 45) / 육척봉 사용 시 공격 속도 (2—4)% 증가 (gi 55) / 창 사용 시 공격 속도 (2—4)% 증가 (gi 61) / 활 사용 시 공격 속도 (2—4)% 증가 (gi 13) — 1티어 이상 훼손 자리

5. 남은 접두를 정리(접두 카오스·접두 소멸 또는 좌측 말소의 징조 + 카오스)한 뒤 카오스로 공격 피해 접두
6. 위력적인 액체 흉포함으로 제작 옵션, 신성한 오브로 치명타 피해 30% 이상

비용: 한 개 약 150 디바인, 훼손 실패 1회 15~16 디바인, 보존된 두개골 약 58 카오스
