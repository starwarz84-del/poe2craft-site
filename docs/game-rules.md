# 게임 규칙 근거표

사이트(레시피 엔진·발굴·에뮬레이터)가 쓰는 게임 규칙과 그 근거예요. 규칙을 바꾸거나 새로 넣을 때 여기에 근거를 같이 적어요.
POE2_HTC 문서에서 확인한 내용은 게임 규칙(사실)만 참고했고, 코드·데이터 표는 가져오지 않았어요(AGPL).

근거 표시:
- **[데이터]** 게임 데이터(poedb·RePoE) 그대로
- **[설명]** 게임 안 아이템 설명·패치 노트
- **[사용자]** 사용자 확정 (CLAUDE.md 정책)
- **[영상]** 원본 영상에서 확인
- **[교차]** 다른 계산기(POE2_HTC 등)도 같은 판단
- **[CoE]** Craft of Exile 데이터(poedb에 값이 없을 때만)
- **[추정]** 공개되지 않아 가정한 값 — 화면에 "추정"·"미확인"으로 표시
- **[미확인]** 제보 한두 건뿐이라 아직 쓰지 않음
- **[Maxroll]** Maxroll "How to Craft in Path of Exile 2"(ZiggyD, 2026-06-18) 가이드에서 확인 — 문장은 옮기지 않고 규칙만 우리 말로 정리(원문 사본은 저장소 밖 `private/maxroll-how-to-craft.txt`)

| 규칙 | 근거 | 사이트 처리 |

| 훼손 전용 옵션은 가중치가 공개되지 않음(데이터상 전부 1). 실제로도 균등하게 나오지 않음 | [데이터] [교차] [사용자] | 그룹당 1000으로 가정, **"가중치 추정"** 표시(2026-11-08) |
| 룬·영혼 핵 전용 옵션 가중치도 데이터상 1 | [데이터] [교차] | 가정하지 않고 **"가중치 미확인"** 표시(POE2_HTC는 1000으로 가정) |
| poedb 가중치가 1(모름)인 일반 옵션 티어 | [CoE] | 같은 레벨 CoE 값으로 채움(358티어, 예: 목걸이 시전 속도 800, 반지 1000), 화면엔 출처 표시 안 함 |
| CoE에도 값이 없는 가중치 1짜리 단독 그룹 | [데이터] | "가중치 미정" 표시 |
| poedb·CoE 둘 다 값이 있는데 다른 12개(예: 근접 스킬 +4) | [데이터] | poedb 값 유지 |
| 촉진하는 찬미의 징조가 퀄리티 속성 옵션 확률을 올리는 정도 | [설명] |

| 완벽/상위 오브의 최소 옵션 레벨: 진화·확장 70/55, 제왕·엑잘·카오스 50/35. 단 그 계열의 최고 티어는 최소 레벨과 상관없이 항상 후보 | [데이터] [교차: pyoe2-craftpath] |
| 심연의 메아리의 징조 = 공개를 한 번 더(두 번 중 한 번 성공) | [설명] [교차: pyoe2-craftpath] | crafting.json `min` |
| 고대 뼈는 레벨 40 미만 옵션이 안 나옴 | [데이터] | 뼈 `min:40` |
| 뼈 훼손은 빈자리가 있으면 거기로, 그 면이 꽉 차 있으면 그 면 줄 하나(분열 제외)를 지우고 들어감. 강령술의 징조는 면만 정함 | [사용자] | 꽉 찬 면 훼손 확률 = 잡옵 수 ÷ 지울 수 있는 줄 수 |

## 화폐·징조

| 규칙 | 근거 |
|---|---|
| 소멸의 오브는 무작위 한 줄 제거. 분열 줄은 안 지워짐 → 남은 줄 수로 나눈 확률 | [데이터] [교차] |
| 빛의 징조 + 소멸의 오브 = 훼손 줄을 확실히 제거 | [설명] [교차] |
| 카오스 오브 = 소멸 + 추가. 분열 줄 안 건드림 | [설명] [교차] |
| 절사의 징조 + 카오스 오브 = **요구 아이템 레벨**이 가장 낮은 줄을 바꿈(티어가 아님). 분열 줄 제외 | [설명] [교차: pyoe2-craftpath] — 검산이 더 낮은 좋은 줄이 있으면 오류, 잡옵이 있으면 주의 |
| 한 면의 다른 좋은 줄이 그 면 최고 레벨 이상이면 절사의 징조 + 완벽한 카오스 오브를 반복해도 그 줄들은 안 지워짐 → 마지막 줄을 안전하게 반복(예: 저항 1티어 82 + 희귀도). 동률 레벨이 새로 뜨면 지워질 수 있음 | [사용자] [설명] |
| 좌측/우측 찬미·소멸·결정화·강령술의 징조 = 그 면으로 제한. 반대쪽이 꽉 차면 징조 불필요 | [설명] [사용자] |
| 반대쪽 면에 지울 수 있는 줄이 없으면(분열 줄뿐) 징조 없는 소멸의 오브도 이쪽 면만 지움 → 분열 반대쪽 면을 먼저 완성해 비싼 징조를 아낌 | [설명] [사용자] [영상] |
| 완벽한 에센스·합금은 무작위 한 줄을 지우고 확정 줄 추가(결정화 징조면 그 면 안에서 무작위) | [설명] [교차] |
| 에센스·합금이 들어갈 면이 꽉 차 있으면 결정화 징조와 상관없이 그 면의 줄 하나가 지워짐(반대쪽을 지워도 들어갈 곳이 없음) | [사용자] |
| 결정화 징조는 지울 면만 정하고, 에센스 옵션은 원래 면에 붙음 → 반대쪽의 버릴 줄(잡옵·최대 퀄리티)을 지워 이미 만든 줄을 지킴 | [사용자] [영상] |
| 제작 옵션(완벽한 에센스·합금)은 1줄까지, 아스트리드의 창의성으로 2줄 | [설명] [교차] [사용자] |
| 심연의 에센스(심연 군주의 징표)도 제작 옵션이라 합금·완벽한 에센스가 있으면 못 씀 | [사용자] |
| 에센스·합금은 줄을 붙인 뒤 지움 → 제작 옵션(균열의 에센스 최대 퀄리티 포함)이 있으면 결정화로 그 줄을 노려도 쓸 수 없음. 먼저 지워야 함 | [사용자] [영상: SL 반지 — 접미 카오스 오브가 최대 퀄리티를 바꿈] |
| 일반/상위 에센스는 매직 → 레어로 올리며 확정 줄. **이 줄도 제작 옵션**(1줄 제한에 셈) | [사용자] [영상: 라그나 아샷활] |
| 검은 피·군왕·군주의 징조는 무기·장신구 훼손에만 | [설명] [교차] |
| 매직 아이템은 접두 1 · 접미 1 | [설명] [교차] |

## 아이템 종류

| 보석의 액체 감정은 보석에 직접 사용(무작위 한 줄 제거 + 확정 줄), 룬 소켓 아님. 제작 옵션 수에 안 셈 | [설명] [사용자] |

| 장신구 퀄리티 상한: 기본 20% + 베이스 고정 + 균열의 에센스 20%, 그 위 바알 촉진시키는 주입기 최대 +10% | [사용자] [영상] |
| 분열은 옵션 4줄 이상에서만, 분열 줄은 이후 지워지지 않음 | [설명] [교차] |

## 앞으로

- **다음 최선 수(MDP)**: 실패할 때마다 그 상태에서 가장 싼 다음 수를 고르는 기대 비용 계산. 서로 다른 화폐를 비교하려면 시세가 필요해서, poe2scout 시세 연동(`S.prices`) 뒤에 진행.
- 소켓 모델링: 숙련공의 오브(룬 소켓 추가)·바알 오브(타락 소켓)를 경로 계산에 넣기(pyoe2-craftpath 참고).
- 훼손 전용 옵션 실제 비율: 공개 결과 기록을 모으면 추정값을 바꿀 수 있음.
