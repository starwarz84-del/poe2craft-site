# 미러템 메뉴 구상 (2026-11-13, 구상 단계 — 아직 만들지 않음)

사용자 요청(2026-11-13 01:59): 시즌별 미러템 레시피, 그 미러템의 원본 거래, 미러템 복사(미러피)를 한곳에서 보는 메뉴. 지금은 구상만.

## 무엇을 보여 주나

시즌(리그)마다 '미러급' 아이템을 카드로 모아요. 카드 하나에 세 가지가 같이 있어요.

| 칸 | 내용 | 출처 |
|---|---|---|
| 아이템 | 옵션 전체(분열·훼손·룬 표시), 베이스, 시즌 | 등록 레시피 완성품 또는 유저 등록 아이템 텍스트 |
| 제작 | 그 아이템을 만드는 레시피·플로우차트로 가기, 직접 만들 때 시뮬 평균 비용(div) | 우리 크래프팅 데이터(있을 때만) |
| 원본 거래 | 원본 판매 여부·가격, 거래소에서 그 아이템을 찾는 검색 링크 | 원본 보유자 등록 + 거래소 검색 주소(`tradeURL` 방식) |
| 미러 복사 | 미러피(div), 복사본 거래 방법, 연락 문구 복사 | 원본 보유자 등록 |

이 메뉴만의 쓸모는 "직접 만들면 평균 얼마 vs 미러피 얼마" 비교예요. 다른 곳은 미러 서비스 목록만 있고, 우리는 시뮬 비용이 있어서 사는 게 나은지 만드는 게 나은지를 바로 보여 줄 수 있어요.

## 화면 흐름(안)

시즌 선택(지금 시즌이 기본, 지난 시즌은 기록) → 부위 드롭다운(에뮬레이터와 같은 두 단계) → 카드 목록(미러피 낮은 순·최근 등록 순) → 카드를 열면 아이템 전체 옵션 + 레시피 보기 + 거래소 검색 + 미러 연락 문구.

## 데이터를 어떻게 채우나(단계)

1. **로그인 없이 바로 가능**: 등록 레시피 중 가격 등급이 '미러'인 것(`priceTier`, 지금 미러 활·미러 지팡이 등)을 시즌별로 모아 카드로. 원본 거래 칸은 거래소 검색 링크만. 미러피 칸은 비워 두고 '등록된 미러 서비스 없음'.
2. **POE 계정 로그인 뒤(로드맵 로그인과 같이)**: 원본 보유자가 아이템 텍스트를 붙여 넣어 등록 → 리버스 분석으로 옵션 확인 → 미러피·판매 여부 입력. 보유자 본인만 등록·수정·내리기. 리버스 초안으로 제작 비용을 붙임.
3. **시즌 기록**: 리그가 끝나면 그 시즌 카드는 '지난 시즌'으로 옮기고 미러 연락 칸은 닫음(스탠다드로 넘어간 원본은 표시만).

## 지킬 것

- 현금 거래(RMT) 사이트로 가는 링크·문구는 넣지 않아요. 검색해 보면 '미러 서비스'를 돈 받고 파는 사이트가 많이 나와요. 거래는 공식 거래소(한글 카카오 trade2·영문 pathofexile.com/trade2)와 게임 안 귓속말로만.
- 캐릭터·계정 이름은 본인이 등록한 것만 보여요. 거래소 결과를 우리가 긁어서 남의 이름을 올리지 않아요.
- 거래소를 자동으로 조회해 가격을 모으는 건 GGG 거래소 이용 규칙·요청 한도를 먼저 확인해야 해요(확인 전엔 검색 링크만).
- 미러된 복사본은 다시 미러할 수 없고 고칠 수도 없어요. 카드에 원본·복사본을 구분해 표시.

## 정해야 할 것(사용자)

- 메뉴 위치: 새 탭 '미러'로 둘지, 크래프팅 안의 필터(가격 등급 '미러')로 둘지
- 1단계에서 미러피 칸을 비워 둘지, 운영자가 알고 있는 미러 서비스를 직접 넣을지
- 시즌 구분 기준: 리그 이름(예: 금단의 의식) vs 패치 버전(0.5, 1.0)
